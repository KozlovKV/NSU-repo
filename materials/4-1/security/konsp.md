# 25.09.05 - Лекция
Основные защитные свойства информации:
- **Конфиденциальность** - информация должна быть недоступной или закрытой для неавторизованных субъектов
- **Целостность** - отсутствие изменений информации либо изменение осуществляется преднамеренно субъектами, имеющими на него право
- **Доступность** - субъекты, имеющие права доступа, могут реализовать их беспрепятственно

Защищённой будет называться система, удовлетворяющая требованиям по защите (**нет требований - нельзя говорить о защищённости**)
